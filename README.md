# 🎮 Bloom City - Game Wiki & Seed Database

A modern, fast, and interactive web application that serves as a comprehensive encyclopedia for Bloom City. Search, filter, and explore in-game items, map seeds, crafting recipes, and world mechanics all in one place.

---

## ✨ Features

* **📦 Item Encyclopedia:** Dynamic database featuring item attributes, drop chances, lore, and crafting trees.
* **🌱 World Seed Index:** Filterable database of map seeds with detailed loot listings and point-of-interest coordinates.
* **🔍 Instant Search & Filtering:** Dynamic client-side search powered by JavaScript for fast item lookups.
* **📱 Responsive Layout:** Clean HTML5/CSS3 design optimized for desktop and mobile devices while playing.

---

## 🛠️ Tech Stack

* **Backend Framework:** PHP / Laravel
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla / Blade Templates)
* **Database:** MySQL / PostgreSQL
* **Templating Engine:** Blade

---

## 🚀 Getting Started

### Prerequisites
